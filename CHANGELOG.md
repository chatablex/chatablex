# Changelog

## [0.1.0-beta.1] - 2026-07-08

First public beta of ChatableX for desktop.

> **Beta notice**: This build is for testing and feedback. It may contain bugs and is not recommended for mission-critical workflows.

### Download

Get the latest installer from the official download page: [https://www.chatablex.com/download](https://www.chatablex.com/download)

### Requirements

- Windows 10 1809+ / Windows 11, 64-bit

### What's included

- Agent Loop Native desktop Agent platform
- Tool Store with session-scoped tool isolation
- Harness Inspector for full execution traceability
- Local sandbox and conversational zero-code tool creation
- Multi-model chat with embedded local backend service

### Known limitations

- macOS and Linux installers are not available in this beta
- Features and performance are still being refined

### Feedback

Report issues via [GitHub Issues](https://github.com/WordsDance/chatablex/issues). Please include your Windows version, install steps, and screenshots or logs when possible.
